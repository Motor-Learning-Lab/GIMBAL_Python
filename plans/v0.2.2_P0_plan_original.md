# v0.2.2 P0 Plan: Module Reorganization

**Status:** In Progress  
**Created:** 2026-01-17  
**Dependencies:** None (foundation for all v0.2.2 work)  
**Estimated Effort:** Medium (1-2 days with testing)

---

## Goal

Restructure the flat `gimbal_pymc/` package (17 modules, ~6,400 lines) into 6 domain-specific subpackages with clearer naming, remove deprecated torch_legacy code, and consolidate duplicate utilities.

**Key Principles:**
- Rename files for clarity during move (document mapping in completion report)
- Require explicit imports from base package (`from gimbal_pymc.hmm import ...`)
- Batch all moves, then fix all imports together
- Maintain backward compatibility via `gimbal_pymc/__init__.py` re-exports

---

## Module Migration Map

### New Structure
```
gimbal_pymc/
├── __init__.py                    # Public API (backward compatibility)
├── hmm/                           # Hidden Markov Model components
│   ├── __init__.py
│   ├── engine.py                  # Stage 1: collapsed HMM
│   ├── directional_prior.py      # Stage 3: directional prior
│   ├── observation_model.py      # Stage 2: camera observation model
│   └── gaussian_example.py       # Gaussian HMM example
├── cameras/                       # Multi-view geometry
│   ├── __init__.py
│   ├── projection.py              # Camera projection utilities
│   ├── triangulation.py          # DLT reconstruction (+ code from fit_params)
│   └── identifiability.py        # Camera placement optimization
├── skeleton/                      # Articulated body kinematics
│   ├── __init__.py
│   ├── config.py                  # Topology & validation
│   ├── synthetic_data.py          # Motion generation
│   ├── metrics.py                 # Quality metrics
│   └── visualization.py           # Plotting
├── joints/                        # Directional statistics
│   ├── __init__.py
│   ├── statistics.py              # vMF parameter estimation
│   └── distributions.py           # vMF distribution for PyMC
├── priors/                        # Prior construction & initialization
│   ├── __init__.py
│   ├── building.py                # Empirical stats → parametric priors
│   ├── initialization.py          # Init strategies (from fit_params, no torch)
│   └── utils.py                   # Distribution helpers
└── data_cleaning/                 # Preprocessing
    ├── __init__.py
    └── cleaning.py                # 2D/3D outlier detection
```

### Phase 4: Code Refactoring (45 min)

**In order of dependency (leaf modules first):**

1. **Remove torch_legacy code:**
   - Delete `gimbal_pymc/torch_legacy/` directory
   - In `priors/initialization.py`:
     - Remove all imports from `torch_legacy.model`
     - Remove `build_gimbal_parameters()` function (legacy only)
     - Keep only numpy-based initialization functions
   - In `examples/run_gimbal_demo.py`: Add deprecation notice, keep for git history

2. **Consolidate `gamma_from_mode_sd()`:**
   - In `hmm/observation_model.py`: 
     - Remove local `gamma_from_mode_sd()` function (lines 33-95)
     - Add: `from gimbal_pymc.priors.building import get_gamma_shape_rate as gamma_from_mode_sd`
   - Keep only version in `priors/building.py`

3. **Extract DLT code from fit_params:**
   - In `priors/initialization.py`:
     - Remove `_triangulate_dlt()` function
     - Remove `_triangulate_anipose()` function
   - In `cameras/triangulation.py`:
     - Add `triangulate_dlt()` (public version, extracted from fit_params)
     - Add `triangulate_anipose()` (public version)
     - Keep existing `triangulate_multi_view()` function
   - Update `priors/initialization.py`:
     - Import from `cameras.triangulation`
