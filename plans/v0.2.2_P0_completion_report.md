## Breaking Changes

### Removed Features
1. **torch_legacy directory:** Entire directory deleted (was deprecated in v0.2.0)
2. **Torch support in initialization:** 
   - `initialize_from_groundtruth()` no longer accepts torch tensors
   - Removed `return_numpy` parameter (always returns numpy)
   - Removed 6 torch-based estimation functions
3. **Legacy torch imports:**
   - No more imports from `gimbal_pymc.torch_legacy.model`
   - No more imports from `gimbal_pymc.torch_legacy.camera`

### Migration Guide
- If using torch-based initialization: Convert data to numpy before calling initialization functions
- If using `build_gimbal_parameters()`: This function has been removed (was torch-only)
- If importing from torch_legacy: Remove these imports entirely
